# 航标灯光巡检台

登记航标实测光强和方位偏差，服务端当场给出合格或不合格。页面由 Django 模板直接渲染，浏览器不另跑一套单页应用。

## 端口

| 服务 | 地址 |
|------|------|
| 页面 | http://localhost:3190 |
| 应用 | http://localhost:8190 |
| PostgreSQL | localhost:54390 |

```bash
cd projects/11-nav-aid-inspection

```

## 批量登记与批次票

巡检员可在"批量登记"页用一张表连续填写多座灯的灯号、亮度和偏角（各座共用本批要求光强），一次提交后逐座判定并分别入库：

- 整批成功：签发一张批次票（票号形如 `B00000001`），把本批新行主键串在票上；结果页逐行列出每座结论。"批次票"页可按票号回看本批。
- 任一行灯号空白（或数值非法）：整批回滚、总表不新增任何实测行，另写一条失败批次尝试（票号形如 `F00000002`），指出是第几行；可在"失败尝试"页查看。
- 只读账号（watch）打不开批量表、看不到失败尝试，只能浏览已成功的批次票。

## 验收

1. 打开 http://localhost:3190 ，用 keeper 登录，列表里 LH-01 合格、LH-09 不合格。
2. 再登记一条光强低于要求的记录，结论为光强不足。
3. 换 watch 登录，没有登记入口；直接提交登记会拒绝。
4. keeper 打开"批量登记"，一座填充足灯光、一座填过暗灯光并提交：结果票一页中一座合格、一座光强不足；总表新增两行且同一票号在"批次票"页可回看。
5. 再提交一批，其中一行灯号留空：跳到失败尝试页并指出行号；总表行数不变，"失败尝试"页留下记录。
6. 换 watch：批量表、失败尝试均为 403；可正常打开成功批次票、按票号回看。
