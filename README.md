# 航标灯光巡检台

登记航标实测光强和方位偏差，服务端当场给出合格或不合格。支持一张表单连续填写多座灯批量提交：逐座判定、分别入库，整批成功后签发批次票；任一灯号空白则整批不入库并记录失败尝试。页面由 Django 模板直接渲染，浏览器不另跑一套单页应用。

## 端口

| 服务 | 地址 |
|------|------|
| 页面 | http://localhost:3190 |
| 应用 | http://localhost:8190 |
| PostgreSQL | localhost:54390 |

## 账号

| 用户 | 密码 | 权限 |
|------|------|------|
| keeper | light123456 | 可登记 |
| watch | watch123456 | 只读 |

## 启动

```bash
cd projects/11-nav-aid-inspection
docker compose up --build
```

## 验收

1. 打开 http://localhost:3190 ，用 keeper 登录，列表里 LH-01 合格、LH-09 不合格。
2. 再登记一条光强低于要求的记录，结论为光强不足。
3. 换 watch 登录，没有登记入口；直接提交登记会拒绝。
4. keeper 打开「批量登记」，第一座填充足灯光（如实测 1400、要求 1200、偏角 0.4），第二座填过暗灯光（如实测 800、要求 1200、偏角 0.2），整批提交。
5. 结果页逐行列出结论：一行合格、一行光强不足，并给出批次票号；总表新增两行且都带同一票号，在「批次票」页按票号可回看这两座。
6. 再试一批，其中一行灯号留空：整批不入库，结果页指出是第几行；总表行数不变，「失败尝试」页留下该批次记录（无新实测行、不发票）。
7. 换 watch 登录：打不开批量登记表和失败尝试页（403），但能在「批次票」页查看已成功的票并按票号回看。
